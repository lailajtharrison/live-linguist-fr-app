# live-linguist-fr-app

Placeholder for the Live Linguist French app. The real code, installer, and releases live in [live-linguist-win](https://github.com/lailajtharrison/live-linguist-win).

**Status:** Empty, as of 2026-10-12. Nothing but this README has been pushed.
**Owner:** Laila Harrison, KSU Office of Research.

Live Linguist listens to spoken French and shows it live as easy-to-read French, called FALC. It runs fully on the computer. Download the Windows installer from the live-linguist-win releases page.
